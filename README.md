# Asmaa Sakr — Portfolio

Personal portfolio: Next.js (App Router) + TypeScript + Tailwind CSS, with a WebGL "neural orb"
(three.js / React Three Fiber), GSAP ScrollTrigger, Framer Motion and Lenis smooth scrolling.

## Run

```bash
npm install
npm run dev        # http://localhost:3000
npm run build && npm start
```

Deploy on Vercel as-is. Optionally set `NEXT_PUBLIC_SITE_URL` (e.g. `https://asmaasakr.dev`) so
canonical and Open Graph URLs use your custom domain.

## Adding or editing projects

All project content lives in [`data/projects.ts`](data/projects.ts). Copy an entry (there is a
commented template at the bottom) and add media to `public/`:

| Field    | File                          | Format                   |
| -------- | ----------------------------- | ------------------------ |
| `cover`  | `public/covers/<slug>.jpg`    | landscape, ~1600×1000    |
| `poster` | `public/posters/<slug>.jpg`   | vertical 9:16, ~1080×1920 |
| `video`  | `public/videos/<slug>.mp4`    | vertical 9:16 MP4 (H.264) |

For a YouTube demo use `video: { type: "youtube", id: "VIDEO_ID" }`.
Until a video exists, the modal shows the poster with "Demo video coming soon".

The current covers and posters are generated placeholders (`npm run placeholders` re-renders them).

## Structure

```
app/                 layout (fonts, SEO, JSON-LD), page, OG image, icon
components/three/    OrbStage (lazy mount, scroll/mouse, fallback), OrbCanvas, NeuralOrb, shaders
components/sections/ Hero, About, Tools, Services, Projects, Clients (map), ResponsibleAI, Journey, Contact
components/projects/ ProjectRow, DemoModal
components/layout/   Navbar, Footer, SmoothScroll
components/ui/       SectionHeading, Badge, Button, TiltCard, CountUp, Marquee
data/                projects.ts, mapDots.ts (generated by `npm run build:map`)
lib/                 gsap, lenis, orb state, reduced-motion hook, site constants
```

## Motion & performance notes

- The orb renders 14k particles on desktop (9k on ≤4-core machines, 6k on mobile), DPR capped at 1.75,
  and stops rendering while the tab is hidden.
- The 3D bundle loads on the first interaction (or after 6 s idle); a CSS gradient orb shows until then
  and remains as the fallback when WebGL is unavailable.
- `prefers-reduced-motion`: a single static orb frame, no smooth scroll, no scroll-scrubbed animation.
